# CNS 航路规划系统

## 新版交互地图入口（本次交付）

性能更新：在线底图已拆成独立 XYZ 瓦片（前端最多 6 个并发请求），不再进入 QGIS 整图渲染。项目中的天地图令牌属于浏览器端，已按用户授权改为浏览器直连，利用浏览器和页面图片缓存；其他代理来源使用后端 64 MB 缓存。本地空域按视口筛选图层，缓存最近 32 个视图，连续缩放取消过时请求。页面显示本地图层更新耗时、在线瓦片耗时和缓存命中块数。界面已改为蓝色顶栏、白色侧栏和浅灰背景。

评审修订已落入 P1 基线：数据源设置改为统一数据源中心，集中显示 QGIS、人口、地形、建筑、空域、障碍、财产、起降点、飞行器、设备及既有 CNS 等来源；当前可替换 QGIS 与人口文件，并可分别检查在线瓦片与地名搜索。健康检查区分文件级检查和后续工作区覆盖检查。风险结果使用多状态，未知项不会被当成通过；环境、技术、生命和财产风险保持独立。完整约束见 `docs/09-后续开发修订基线.md`。

**推荐：双击本工程的“启动地图.cmd”。** 等待数据加载后会自动打开系统默认浏览器。启动失败时窗口保留错误提示，详细日志在 `outputs/map-server.log`。

`python app.py`、`python map_app.py` 均启动新版地图；原来的 Streamlit 8501 入口也会自动启动并嵌入新版地图。旧版元信息演示已移至 `legacy_app.py`。

```powershell
python map_app.py
```

打开 http://127.0.0.1:8765 。使用电脑已安装的 QGIS Python 运行真实地图，无需另装 GIS Python 包。启动器自动查找 `C:\Program Files\QGIS *`；其他安装位置可通过 `CNS_QGIS_PYTHON` 指定 `python-qgis*.bat`。保留终端，Ctrl+C 停止。

- 左侧六步导航 + 右侧地图；拖拽、滚轮、双击、加减按钮缩放；图层区域或经纬度定位。
- 默认加载用户指定 QGZ 及其同目录 GeoPackage；保留本地空域图层样式，人口 GeoTIFF 可叠加，透明度可调。
- 点击“数据源设置”→“浏览电脑…”：支持盘符、目录、上一级、目录路径输入及文件选择。QGZ/QGS 与 TIF/TIFF 分别筛选。选择后点“应用数据源”。这是页面内的本机文件浏览器，不上传到外部服务。
- 替换时先校验；缺少 QGZ 引用文件或栅格无效会报错并保留当前有效地图。路径设置写入 `projects/map_sources.json`，下次启动恢复。源文件不修改。
- QGIS 在线底图默认关闭，需要网络才能开启。本地空域和人口显示不依赖在线瓦片。人口配色是密度展示，不是风险分级；当前第 1 波段、业务单位人/km²，元数据未提供单位/来源时间，仍需核对数据说明。

本次为独立 Python + QGIS 地图前端，浏览器使用本地 HTML/CSS/JavaScript 交互，无 CDN。原 Streamlit 元信息入口保留如下。两入口目前不共享项目状态；新版尚未接入航路算法、布站和成果报告。

## 启动（Windows PowerShell）

在本工程目录打开终端，当前电脑已有 Python 3.13.9 和 Streamlit 1.51.0，可直接运行：

```powershell
python -m streamlit run legacy_app.py
```

浏览器打开 http://127.0.0.1:8501 。停止服务在终端按 Ctrl+C。若端口占用，加 `--server.port 8502` 并访问相应端口。

新环境建议隔离安装，无需激活脚本：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m streamlit run legacy_app.py
```

仅依赖安装需要网络；离线部署安装包在第七阶段提供。当前不必安装 geo 可选依赖。只监听本机地址，不提供公网服务。

## 第一阶段手动验收（约 5 分钟）

1. 在第 1 步输入项目名，选择单条或多条航路，创建项目；侧栏显示名称、模式和 ID。
2. 第 2 步输入自己的区域西、南、东、北经纬度并应用，查看边界示意。将西经度设为大于东经度，应报错且保留旧边界。
3. 点击侧栏“保存元信息 JSON”，确认下载文件存在。刷新浏览器后，在第 1 步选该文件并点打开，确认名称、ID、模式和边界恢复。
4. 查看第 3–6 步，均须明确显示未实现，不出现规划通过或可靠性达标。
5. 尝试打开内容为 `[]` 的 JSON，应报错；已有项目时先勾选允许替换。错误文件不得覆盖旧项目。

当前 JSON 仅保存元信息，不是完整备份；修改后须重新下载。边界图不按比例、不可平移框选，不用于距离面积计算。未提供真实地形，未做净空校验。
