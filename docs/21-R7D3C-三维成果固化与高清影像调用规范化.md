## 4. 天地图浏览器端 TK 的服务端代理审查

### 4.1 官方规则

天地图 Key 在控制台按调用场景分为“浏览器端”和“服务端”两种权限类型；服务端
按 Key 类型校验来源。QGIS 项目里的 `tk` 是浏览器端 Key。用默认 Python UA 请求
会得到 `403 / 301012「Key权限类型为:浏览器端，请使用浏览器访问！」`。

### 4.2 R7-D3B 的问题

R7-D3B 为了让浏览器端 Key 在服务端可用，注入了 Chrome UA 和
`Referer: https://www.tianditu.gov.cn/`。这属于**伪装调用来源、规避 Key 类型
权限**，不是官方允许的接入方式，R7-D3C 明确禁止。

### 4.3 本轮修正

- 删除 `BROWSER_USER_AGENT` 与 Referer 注入；代理请求只带
  `Accept: image/*` 和 `Connection: close`。
- 天地图代理只读取 `CNS_TIANDITU_SERVER_KEY`（官方服务端 Key）。
  `CNS_TIANDITU_TK` 只用于披露“浏览器端 tk 存在但未使用”，绝不参与请求。
- 未配置服务端 Key 时：
  - `imagery/config`：`hd_status=pending_configuration`、
    `hd_reason_code=tianditu_server_key_not_configured`、`hd_available=false`、
    `authorization_status=pending_configuration`、`hd_delivered_m_per_px=null`；
  - 瓦片端点保留（`/api/visualization-3d/imagery/tianditu_img_w/{z}/{x}/{y}`），
    但本地 fail-closed 返回 `tianditu_server_key_not_configured`，不触网；
  - 前端在线单选置灰，标签显示“天地图高清影像（待配置：缺少官方服务端 Key）”；
    **不创建 Cesium imagery provider**，不会产生一次注定失败的请求。
- 保留 Sentinel-2 L2A 10 m 离线底图作为默认兜底；它不读凭证、不占预算、不触网。

## 5. 内部请求预算与官方免费配额

| 概念 | 位置 | 性质 |
|---|---|---|
| `TIANDITU_INTERNAL_DAILY_REQUEST_BUDGET=1200` | `imagery_budget.py` | 本项目内部上游请求保护上限 |
| `TIANDITU_INTERNAL_SESSION_REQUEST_BUDGET_BY_MODE={smoke:60,manual:300}` | 同上 | 内部会话上限 |
| 官方免费配额 | 未取得 | `official_quota_verified=false`、`official_quota=null` |
| ArcGIS 计费预算 | `DAILY_LIMIT=150` / `SESSION_LIMIT_BY_MODE` | 独立计数文件，与天地图不共享 |

`imagery/config` 同时返回 `budget`、`tianditu_internal_request_budget`、
`tianditu_official_quota`。内部阈值不得解释为官方免费额度，也不得用于对外承诺
“每天可调用 1200 次”。

**密钥边界**：服务端 Key 只从进程环境变量读取；不出现在 Git、前端配置、
`imagery/config` 响应、日志或错误消息中。前端只看到本地代理 URL。
