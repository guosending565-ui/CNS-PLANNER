# 阶段计划与验收

时间为一名熟练 Python 开发全职估算，非交付承诺；每阶段交付后由用户验证，再继续下一小阶段。总计约 8 周，另留 1–2 周缓冲。

| 阶段 | 目标与交付 | 验收方式 |
|---|---|---|
| 1（当前） | 需求基线、设计字典、工程骨架、六步导航、元信息 JSON、边界示意 | 按 README 创建/保存/恢复；非法文件不覆盖当前项目；自动冒烟通过 |
| 2 | 项目包、原子保存/另存/恢复；GeoTIFF 窗口检查、铁塔映射；交互地图技术验证 | 真实人口小范围读取；CRS/NoData/缺覆盖可见；移动项目可恢复；无网络图层交互仍可用 |
| 3 | 单/多航路、起降点、连接与导入、方向高度、场景与运行实体 | 删除/移动/重建保留既有编号；模式转换另存无丢失；逐条勾选 |
| 4 | 标准网格 A* 插件、工程风险与硬约束 | 无路失败、对角不穿角；不同地区/跨带策略；换算法无需改报告接口 |
| 5 | 设备与规则、累计距离布站、铁塔共址、人工调整 | 曲线按累计里程布点，共址移动后重验；C/N/监视设备独立 |
| 6 | 逐航路覆盖、共享站址、输入失效重算闭环 | 缺必需系统判缺失；已知几何案例验证长度与重数；修改使相关结果失效 |
| 7 | 各种导出、报告、项目备份、安装打包 | 输出可重新读取；报告含失败和未检查项；离线干净环境启动 |
| 8 | 联调、验收修复、用户及维护手册 | 真实数据端到端、多地区回归；用户按手册独立完成流程 |

## 第一阶段实际边界

当前不是完整规划器；没有航路、设备、覆盖结果或业务报告。保存恢复仅针对项目 ID、名称、模式及矩形边界，刷新/关闭前需下载。原地保存、另存、完整数据打包留至第二阶段。模式仅在创建时选择，当前无航路模式转换入口。

地图方案优先评估 Folium/streamlit-folium，尚未完成交互组件验证。当前 SVG 只验证离线展示通路，不具备平移、框选、按比例测绘功能。第二阶段必须检查组件 JS/CSS 是否依赖 CDN，必要时随应用打包资源；在线瓦片是可选层，离线不能出现无法操作的空白面板。

## 下一次最小任务（2A）

先只读检查现有 GeoTIFF 元数据与一个用户项目范围的窗口：CRS、NoData、范围、像元大小、波段、来源时间和单位。建立数据清单及质量结果，不做全国栅格全量载入。随后做项目包与铁塔字段映射，不同时展开所有算法。
