# 需求基线 v0.1

日期：2026-09-08。以本次用户确认的六步流程为实施依据；旧草稿仅作交互参考。本文件记录需求，不代表功能已实现。

## 范围与验收原则

- Python 完整工程，单机、本地浏览器；Streamlit 仅负责 UI，业务算法独立。安装依赖需要网络或离线安装包，安装后核心工作不依赖在线服务。
- 全国按项目区域处理，不硬编码城市、边界或网格原点；首期不承诺全国全量计算。
- 结果统一使用 `not_calculated / missing_data / pending_confirmation / passed / failed / not_applicable / stale`；任何汇总不得掩盖逐航路失败。只有所有必评项通过或明确不适用时，汇总才可通过。
- 输入变更必须使依赖结果失效；报告保留参数来源、模型版本与未完成检查。
- 数据健康分为数据源健康和工作区健康。启动时只做来源文件检查，工作区定义后再做空间覆盖检查；在线瓦片和地名搜索独立报告状态。

## 六步业务

| ID | 页面 | 必须实现的业务与验收 |
|---|---|---|
| B01 | 项目与数据 | 新建、打开、保存、另存；单/多航路。单转多保留航路，多转单选择保留航路并优先另存。数据预览、映射、检查，项目保存恢复。 |
| B02 | 工作区与基础环境 | 框选或导入边界、图层控制、范围及质量检查；无有效区域不能计算。 |
| B03 | 航路 | 起降点、手动连接、批量导入、两两连接，逐条勾选；编号稳定且不复用，方向和高度；场景航路与运行航路独立保存，逐条里程与结果；多条航路不得拼接。 |
| B04 | 运行规则 | 飞行器、速度、可选 MTBF 技术可靠性；方向间高度/间隔、延时；C/N/监视必需能力及覆盖要求，项目默认与航路覆盖配置。 |
| B05 | 设备与布站 | 设备库、固定半径、可用铁塔共址、累计航路距离规则布站、共址后重验、规则补盲、人工增删移动替换；物理站址共享，设备分系统独立。 |
| B06 | 确认与导出 | 航路 GeoJSON/CSV；站点 Excel/CSV/GeoJSON；逐航路统计、HTML/PDF 报告、项目备份；确认针对当前有效结果。 |

## 数据与空间计算

人口：政府部门提供的 GeoTIFF，业务约定单位人/km²；记录来源部门、时间、CRS、NoData、分辨率、范围、波段和单位确认。NoData 不等于零人口，范围缺失不能默认为低风险。窗口读取项目范围，估算内存并限制网格规模；人口总量须按像元实际面积积分，不能把密度值直接相加。

铁塔：运营公司提供 CSV、Excel、GeoJSON、Shapefile，显式字段映射及 CRS/坐标系确认。Shapefile 检查配套文件；保留原始值及映射记录，检验重复 ID、非法坐标、缺失字段和共址资格。

地形：真实 GeoTIFF；保留垂直基准与高度单位。未提供时明确“未做净空校验”。建筑、空域硬约束与地形检查分别记录，不以地形代替障碍物。

交换/显示坐标使用明确的经纬度 CRS；原始 CRS 元数据保留。距离面积不得直接用经纬度或 Web Mercator 计算。局部区域采用适宜米制投影并检查畸变；跨投影带/大区域采用测地线或分区处理并记录策略。CGCS2000、WGS84、GCJ-02 不得无条件等同；缺失 CRS 要求补充后才能分析。第一阶段边界输入明确为 WGS84，仅用于示意。

## 算法和判定

- 路由统一输入输出、算法注册、选择与配置；首个实现为标准网格 A*，后续算法无需修改业务与报告模块。这里“标准网格 A*”不代表已实现任何法规网格编码。
- 硬约束不可穿越，包含对角穿角和路径段相交检查；无路返回 no_path，不回退直线。每条航路独立返回状态及输入指纹。
- 环境/航路规划风险、MTBF 技术失效风险、人员生命风险和财产风险分别建模、存储和展示。GRC 只用于环境/航路规划风险分级接口，MTBF 只用于技术可靠性接口，二者不得混用。
- 生命与财产风险先建立数据结构和接口；模型、单位、阈值与数据源未确认前保持待计算或待确认，不参与正式通过判定。
- 固定水平覆盖半径；不计算传播、遮挡、干扰或高度对半径的影响。不做 MILP、最少站点或成本优化。
- 覆盖逐航路、逐必需分系统报告：覆盖长度比例、最小重数、长度加权平均重数、未覆盖长度和缺口几何。必需分系统没有设备须判缺失；不要求的系统显式不适用。长度比例不能用不等距采样点个数代替。
- `1e-6` 仅记录为技术安全目标原型阈值，事件定义、公式和来源尚待确认；不得称为生命或财产风险阈值，不参与首期达标判定，也不阻塞覆盖功能。

## 对参考原型的处置

| 参考行为 | 新工程决定 |
|---|---|
| 固定 LON0=120 / LAT0=28、城市预置数据 | 删除依赖，依据项目范围生成计算网格 |
| 合成人口、DEM、当地风险 | 不移植；无数据明确缺失 |
| 贪心路径和绕行回退直连 | 用独立 A* 替换，失败无路径 |
| SORA/GRC 合成分级标签 | 保留 GRC 环境/航路风险接口；与技术、生命和财产风险分开 |
| G1 原型累加公式与 MILP 路线 | 不作为正式门槛、不纳入优化 |
| 拼接 astarPath | 改为 route_id 到独立结果的映射 |
| 固定 0.9R、共址 2km、净空 30m | 作为带来源且待确认的可配置工程默认值，不视作全国规范 |
| 六步导航、场景/运行分离、稳定编号、分层展示 | 保留业务意图，重新实现 |
