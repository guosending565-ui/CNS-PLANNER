# 19 · 三维系统资产与恢复说明（R6-C）

> 配套文件：仓库根目录 `PROTECTED_ASSETS.md`（受保护清单与 SHA）。
> 本文只讲**怎么恢复、怎么验证、怎么排错**；不做任何合并或清理决定。

---

## 1. 恢复目标

在任意一个干净工作树上，恢复出与 8776 当前运行实例**等价**的三维能力：

- 三维页面 `/visualization-3d.html`（Cesium，无构建步骤）；
- `/api/visualization-3d/*` 只读白名单（manifest / routes / terrain / imagery /
  communication / RID / Radar / 保护区 / CNS 站址 / 固定保障带 / 模拟入侵）；
- 地形瓦片（FABDEM + EGM2008）与影像代理（离线模式）；
- 三维航路、铁塔、CNS 设施、RID、通信、Radar、保护区等既有功能。

**前提**：不要把三维系统当成"可以随手重写"的页面。它是 7 个内容一致的工作树里的同一份
正式跟踪源码；恢复 = 找到正确版本，而不是重新实现。

## 3. 验证清单（只读）

### 3.1 四个关键端点

```powershell

Invoke-RestMethod http://127.0.0.1:8778/api/visualization-3d/manifest
Invoke-RestMethod http://127.0.0.1:8778/api/visualization-3d/terrain/layer.json
Invoke-RestMethod http://127.0.0.1:8778/api/visualization-3d/imagery/config
```

期望：

- `health`：`ready=true`；
- `manifest`：`schema_version=visualization-3d/v1`，`terrain.path` 指向 FABDEM，
  `terrain.sha256` 与文件一致；
- `layer.json`：`tilejson=2.1.0`、`format=heightmap-1.0`、`scheme=tms`、`maxzoom=13`；

R7-A 追加的两个必查项（缺一即"文件在、页面不可用"）：

- `routes`：HTTP 200（可空，但**必须**是 200 而不是 404——404 说明落到了静态解析）；
- 页面与其静态资源：`/visualization-3d.html`、`/js/visualization3d/app.js`、
  `/vendor/cesium/Cesium.js`、`/vendor/cesium/Widgets/widgets.css` 全部 200。

上述 9 项可用一条命令完成（只读）：

```powershell
D:\tools\anaconda\python.exe tools/verify_3d_assets.py --root <恢复后的工作树> --probe http://127.0.0.1:8778
```

### 3.2 十三个图层

`terrain_fabdem`、`route_geometry_demo`、`route_geometry_canonical`、`towers`、

  `manifest` 13 个图层齐全，`terrain.sha256` 与 FABDEM 实际文件一致，影像 `status=offline_mode`；

## 4. 排错

| 现象 | 检查 |
|---|---|
| 页面 404 | `visualization-3d.html` 是否在 `cns_planner/web/`；服务是否指向正确工作树 |
| 页面能开但地球黑屏 / 控制台报 Cesium 未定义 | `cns_planner/web/vendor/cesium/` 是否随 15 个文件一起恢复（8 个文件、5.7 MB）；跑 `tools/verify_3d_assets.py` |
| 某个三维模块 404 | `cns_planner/web/js/visualization3d/` 是否 9 个模块齐全（少一个即整页白屏，ES Module 报错不静默） |
| `manifest` 404 | `router.py` 是否含 `VISUALIZATION_3D_ACTIONS` 白名单 |
| 地形全平 | `terrain_dtm` 路径/权限；`manifest.terrain.sha256` 是否与文件一致 |
| `egm2008_grid_missing` | EGM2008 网格未登记；**不要**用 0 代替 |
| 影像黑屏 | `imagery/config.status`；离线模式只允许登记过的离线源 |
| 某图层空 | 该图层依赖的上游结果是否 `stale/not_calculated`（三维不重算业务结果） |
| 前端脚本报错 | 浏览器控制台；`node --check` 各 `visualization3d/*.js` |

## 5. 已知限制（不是缺陷）

- 影像默认离线模式，在线影像需要显式授权与凭据，**不会**在读配置时暴露凭据；
- `cns_sites` 的四类身份来自上游证据，三维层**不推断安装**；
- Radar 是方向性覆盖示意，不是认证覆盖；
- 保护区/隔离工程示意来自 P17 历史保护走廊，只读；
- 固定 1000 m 保障带只画外环，不重算 buffer；
- N（导航增强）没有三维几何模型，不能在三维图层里"补"出来。

## 6. 回滚与隔离

- 恢复过程中**不要**改动原工作树；复制到新树验证通过后再决定后续。
- 需要停掉验收实例时，用 `job_kill`/`Stop-Process` 停**自己启动**的进程；
  8776 属于既有验收环境，不得由本流程停止。
- 任何"清理"动作前，重新执行 `PROTECTED_ASSETS.md` §7 的 8 条前置条件。
