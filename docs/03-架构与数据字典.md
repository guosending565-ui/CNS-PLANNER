# 架构与数据字典

## 分层

入口 app.py → ui（Streamlit）→ 未来 application 服务 → domain / algorithms / 未来 GIS 与覆盖模块。storage 负责序列化。业务模块不导入 UI。当前仅有元信息模型、JSON 存取、路由协议/注册表，算法注册表为空；不会将占位算法称为可计算算法。

未来按需加入 gis（数据适配、CRS、窗口读取）、services（业务编排和失效）、coverage（圆与航路交段）、siting（规则布站）、reports（只读取有效结果及问题清单）。避免先铺设大量空模块。

## 实体字典（除 Project 外为设计稿）

| 实体 | 核心字段与单位 |
|---|---|
| Project（已实现） | schema_version=1、id UUID、name、mode single/multi、bbox=[西,南,东,北] WGS84 度或 null |
| Dataset | id、role、项目内相对路径、checksum、来源部门/日期、原始 CRS、单位、NoData、范围/分辨率、映射、质量问题 |
| Region | 边界几何与 CRS、分析投影策略、最大网格/内存预算 |
| Endpoint | 稳定 id、名称、经纬度、原始 CRS、地表高度及来源 |
| Route | 稳定 id、端点 id、方向、各方向高度及基准、selected、scenario_geometry、operation_result_id、规则覆盖配置 |
| OperatingRules | 飞行器、速度 m/s、可选 MTBF h、延时 ms、高度 m、距离 m、C/N/S 各系统必需标志与覆盖阈值及来源 |
| Device | id、subsystem C/N/S（S 为监视）、radius_m、主/补角色、可选 MTBF h、参数来源 |
| Site / Installation | Site 是物理位置/可用塔 id；Installation 将设备实例挂在 Site，多个航路共享同一物理站址 |
| RouteResult | route_id、status、path、algorithm_id/version、input_fingerprint、reason；失败 path 为空 |
| CoverageResult | route_id、subsystem、覆盖/未覆盖长度 m、覆盖比例 0–1、最小/长度加权平均重数、缺口几何、阈值、状态、指纹 |
| TechnicalReliabilityResult | MTBF、事件定义、模型/来源、输入指纹、单位、阈值、状态和评估值；未确认时为 pending_confirmation |
| EnvironmentRiskResult | 环境/航路规划风险值、GRC 接口、模型/来源、输入指纹与状态；不得混入 MTBF 结果 |
| LifeRiskResult / PropertyRiskResult | 模型、单位、阈值、数据源、输入指纹、状态和评估值；字段未确认时只保留接口和状态 |

## 路由接口约定

RouteRequest 是单条航路的米制规则网格输入：宽高、单元米长、分析 CRS、网格原点、起终单元、blocked 集合、risk 映射、配置与指纹。网格 x 向东、y 向北；单元中心为 origin+(index+0.5)*cell_size。风险缺失处理在实现阶段明确为非法输入或屏蔽，不隐式当零风险。GIS 适配器负责将真实数据转换到此契约。UI 保存算法 ID/版本和配置，服务从注册表选择算法；测试用插件不进入生产注册表。

## 保存与失效设计（第二/六阶段实现）

完整项目目录计划包含 manifest.json、data/、results/ 与审计记录；清单带 schema_version，未来版本拒绝直接读取，迁移显式执行。数据引用使用相对路径与哈希；不依赖 D 盘参考目录。写入临时文件并原子替换，备份保留上一版。

依赖指纹包含数据内容/CRS/边界、航路、规则、设备、算法与模型版本。人口/约束/边界变化→运行航路/布站/覆盖/报告失效；航路几何变化→该航路及共享站址影响范围失效；半径/站址变化→相关覆盖/报告失效；仅名称变化→报告失效。重算失败也不能显示上次成功为当前结果。首次可保守地扩大失效范围，不能漏失效。

当前已提供保守依赖失效服务，后续业务结果接入时使用。阶段六需验证：`not_calculated / missing_data / pending_confirmation / passed / failed / not_applicable / stale` 全部状态，任何未知状态均不能生成 `overall_pass=true`。
