## C 根因

22 个几何有效候选均为 unknown。首个实际返回门禁为机地接口证据不足（ground interfaces=[]）；并非 provider 身份丢失：设备和 action 均声明 C:communication。

逐字段核查当前 COMM-BASELINE-2KM：type.technology=unknown、type.network_scope=unknown、type.interfaces=[]；performance.max_latency_s、lost_link_threshold_s、max_continuous_outage_s、max_cumulative_outage_s、min_availability、min_redundancy 均为 null；service_model.model_family=unsupported、status=missing_data、technology=unknown、parameters={}。因此仅补接口仍不能得到合法能力结论。几何半球与 2000m 范围不提供通信链路、吞吐、延迟或可靠性事实。可靠性 MTBF/可用度也缺失。

安装方面：候选使用 inherited planning origin / 工程安装假设，既无真实设备安装确认，也无现场独立站址勘验；不能升级为 installed_confirmed。当前 C 没有已支持的 assumption-only 服务模型，故不做 C 单候选模拟，不猜填型号能力或性能。下一步须提供可解释的服务模型、机地匹配接口和需求对应性能证据；真实安装确认仍另需现场依据。
