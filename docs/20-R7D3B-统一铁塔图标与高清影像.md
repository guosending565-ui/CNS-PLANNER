### 3.2 国家天地图（实际接入）

采用 `https://t0.tianditu.gov.cn/img_w/wmts`：

- `LAYER=img`、`TILEMATRIXSET=w`、`FORMAT=tiles`、`TILEMATRIX={z}`、`TILEROW={y}`、`TILECOL={x}`。
- 在浏览器与带浏览器 UA 的服务端请求下均返回 `200 image/jpeg`、`256 × 256`。
- **最高有效层级 z18**；z19/z20 虽返回 200，但内容是 `image/png` 的 4769 B 占位图，文字为“此级别下，该区域无影像，请放大或缩小地图后再浏览”，不是更高清影像。
- 因此页面标注为“天地图高清影像（z18，约 0.52 m/px）”，**不宣称源影像 GSD 一定为 0.5 m**；`hd_delivered_m_per_px=0.52`，`hd_max_zoom=18`。

#### 关键坑：浏览器端 Key

QGIS 项目里的 `tk` 是**浏览器端** Key。用 Python 默认 `python-urllib` UA 请求会得到：

```text
HTTP 403 {"resolve":"Key权限类型为:浏览器端，请使用浏览器访问！","msg":"权限类型错误","code":301012}
```

修复：服务端代理注入正常浏览器 `User-Agent` 与 `Referer`，Key 只在服务端拼接，前端只看到 `/api/visualization-3d/imagery/tianditu_img_w/{z}/{x}/{y}`。`credential_exposed=false`，配置响应不含 Key。

#### 独立预算

天地图是免费公开源，但 Cesium 一屏会请求几十张瓦片，原有 ArcGIS 计费预算 80/150 会立刻耗尽，表现为“父级瓦片被拉伸成整屏”的假高清。因此新增：

- `imagery_budget_tianditu.json` 独立计数文件；
- `FREE_DAILY_LIMIT=1200`、`FREE_SESSION_LIMIT_BY_MODE={smoke:60, manual:300}`；
- ArcGIS 计费源仍为 150 日 / 80 会话，互不共享计数；
- 天地图瓦片只做**进程内 LRU 缓存**（512 张，不落盘、不预取），命中不触网、不占预算。

### 3.3 高清图层范围与切换
