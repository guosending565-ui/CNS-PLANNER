## 7. 干净检出校验清单（D3 用）

```powershell

git rev-parse HEAD                      # 期望候选提交（D2 后）

# 3) Cesium 许可与运行字节（LF 规范化；PNG 用原始 SHA）
D:\tools\anaconda\python.exe -c @"
import hashlib
from pathlib import Path
root = Path('cns_planner/web/vendor/cesium')
expect = {
 'LICENSE.md': '3111d10e1630bfa975251018149c973a0a3f42d11e793733a8ce417d52baa59a',
 'Cesium.js': 'b796f8a6f695d610cef6b86a2a51adb759b20c71ba643403a9b4489144a697e0',

}
for rel, want in expect.items():
    raw = (root / rel).read_bytes().replace(b'\r\n', b'\n')
    got = hashlib.sha256(raw).hexdigest()
    print(rel, 'OK' if got == want else 'MISMATCH', got)
"@
# 期望：三项均 OK（LICENSE.md 3111d10e…、Cesium.js b796f8a6…、widgets.css 702c5adf…）

# 4) 研究服务（只读）

# 3D: http://127.0.0.1:<port>/research_3d.html?run=<run_id>
```
